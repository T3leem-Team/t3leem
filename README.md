T3leem — School Management Dashboard

A school management system built with Next.js to help manage school operations, teachers, students, and attendance.

Live Website

https://t3leeem.vercel.app

Built With

Next.js

TypeScript

Supabase

Tailwind CSS

Development

To run the project locally:

pnpm install
pnpm dev

Open http://localhost:3000 in your browser.

Deployment

The project is deployed on Vercel. Changes pushed to the main branch can trigger automatic deployments.
